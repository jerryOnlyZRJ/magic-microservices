# Playground

This page gathers the three best demos for getting hands-on with Magic. Edit the code directly inside the docs, observe the runtime behavior, and then jump back into the deeper conceptual pages when you are ready.

## What you can try here

- explore the smallest registration loop and see how `magic()` turns a module into a native browser tag
- change the `useProps()` callback logic and watch reference values flow through the runtime
- adjust the module-composition demo and see why Magic is optimized for module delivery rather than full app orchestration
- compare every adapter demo and try the default examples for React 18, React 17, Preact, Vue 3, and Svelte
