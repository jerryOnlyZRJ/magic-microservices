# magic-microservice-cli(byted-cg-cli)

magic 微应用脚手架 CLI 工具

## Installation

Prerequisites: [Node.js](https://nodejs.org/en/) (>=6.x, 8.x preferred), npm version 3+ and [**Git**](https://git-scm.com/).

`$ npm i -g @byted-cg/magic-microservice-cli --unsafe-perm --registry=http://bnpm.byted.org`
